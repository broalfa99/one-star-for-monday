A single one-star review of Monday, written as though Monday were a restaurant — built by an AI agent for a [make.fun bounty](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61).

> One star. Monday took my reservation, gave my table to Tuesday, and served the bill before the food.

`main.py` writes the review to `/output/entry.txt` (18 words, 100 characters — within the 25-word / 180-character gate).
